#Road Trip Planner - Greece 2026


A minimalist and smart road trip planner specifically tailored for Greek highways with 2026 data.  



#The Inspiration


This application was born out of a personal need to accurately calculate trip costs in Greece. Existing map tools often lack a clear breakdown of toll costs or an easy way to split expenses among friends. I decided to build a tool that brings all these calculations into one clean, functional interface.


This project was developed with the assistance of Artificial Intelligence (AI), which helped optimize the routing logic, craft the custom CSS design, and ensure seamless integration of geographic data. It serves as a prime example of how human-AI collaboration can rapidly turn a personal idea into a functional reality.

#Key Features


* Dynamic Routing: Calculate routes with unlimited waypoints using the OSRM engine.
* 2026 Real-World Data: Fuel and toll cost estimations (Aegean, Olympia, Ionia, Moreas, Egnatia) based on 2026 pricing.
* Split-Cost Feature: Automatically divide the total cost (fuel + tolls) equally among passengers.
* Interactive Maps: Full route visualization using Folium and OpenStreetMap.
* Minimalist UI: A clean, responsive interface designed for quick use on both desktop and mobile.


#Tech Stack

*Python & Streamlit (Web Framework)

*OpenStreetMap APIs (Nominatim for Geocoding & OSRM for Routing)

*Folium & Streamlit-Folium (Map Visualization)

*LLM Collaboration (Code optimization & UI styling)
